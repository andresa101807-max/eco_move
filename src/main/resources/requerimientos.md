#proyecto eco move 

## requisitos 
quiero crear un api rest con springboot, que me permita manejar el crud de eco move  
debe permitir Registrar, consultar, actualizar y eliminar datos de vehículos, usuarios, rutas, reservas y mantenimientos, almacenando la información en archivos CSV
debe Implementar jerarquías de clases para reflejar distintos tipos de vehículos y sus comportamientos (herencia y polimorfismo).
debe Utilizar interfaces para definir comportamientos comunes (por ejemplo, vehículos recargables, autónomos, o con sensores IoT).
debe Aplicar composición y agregación para modelar relaciones entre objetos (por ejemplo, un vehículo con su batería, un usuario con su historial de viajes).
debe Incluir enumeraciones para representar estados (disponible, en mantenimiento, reservado) y records para objetos inmutables como coordenadas o estadísticas de uso.
quiro que manejes nombremientos en ingles 
mvc , conservando  principios SOLID  , KISS y DRY, persistir la informacion en un archivo separado por comas,
